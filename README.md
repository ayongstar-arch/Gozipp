## 🛠️ วิธีการรันโครงการ (Running Locally)

**ความต้องการของระบบ:** Node.js v20+

1. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
2. รันแอปพลิเคชัน:
   ```bash
   npm run dev
   ```
3. ตรวจสอบประเภทโค้ด (Type Check):
   ```bash
   npx tsc --noEmit
   ```
